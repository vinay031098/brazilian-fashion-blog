## Interactive Elements

### Hover Effects
```
Blog Card:
┌──────┐       ┌──────┐
│      │       │      │  ← Hover
│Image │  →    │Image │  • Shadow grows
│      │       │      │  • Scale 1.05
└──────┘       └──────┘  • Title color changes
```

### Buttons
```
Primary Button (Green):
┌────────────────┐
│ Explore Now    │  Hover → Darker green
└────────────────┘

Secondary Button (Coral):
┌────────────────┐
│ Learn More     │  Hover → Darker coral
└────────────────┘
```

### Category Badges
```
🏷️ Fashion     (Coral background, white text)
🏷️ Beauty      (Ocean background, white text)
🏷️ Sustainable (Green background, white text)
```

## Animations

### Page Load
- Hero: Fade in from top
- Blog cards: Stagger fade in
- Sections: Fade in on scroll

### Interactions
- Button hover: Smooth color transition
- Card hover: Scale + shadow
- Menu: Slide in from top

## Responsive Breakpoints

```
Mobile:     < 768px   (1 column)
Tablet:     768-1024px (2 columns)
Desktop:    > 1024px   (3 columns)
Large:      > 1440px   (Max width container)
```
